Spiral Grid — Per-Cell Scrolling Prototype

Stress-tests the spiral-grid__content--scroll, --scroll-x, and --scroll-y modifiers. Each demo annotates the rotation applied to each cell so you can verify wheel/touch behavior is intuitive in screen space (not cell-local space). See doc/cell-scrolling.md for design notes.

  • Wheel test: hover any scrollable cell and spin the mouse wheel vertically. Content should scroll up/down in screen coordinates, regardless of the cell's rotation.
  • Touch test (mobile/trackpad): two-finger scroll on rotated cells (90°, 180°, 270°) should feel natural.
  • Scrollbar hygiene: the scrollbar should sit inside the clip (never truncated) thanks to the auto safe-zone.
  • Scroll chain: scrolling past the end of a cell should NOT scroll the page (overscroll-behavior: contain).

3. Horizontal scroll — --scroll-x

Image strip or timeline use case. Works the same inside rotated cells: the strip should still scroll along the cell's counter-rotated local-X, which is screen-X for unrotated cells and screen-Y for 90° cells. This is worth understanding: --scroll-x is cell-local horizontal, not screen-horizontal.
