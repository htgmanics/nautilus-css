Spiral Grid — Gap Feature Prototype

Experimental --spiral-grid-gap implementation via clip-path: inset(). Each cell is clipped inward by (gap / 2) / pow(phi, i), so the post-scale visual gap between neighbors equals --spiral-grid-gap regardless of cell depth. The dark stage color shows through the gap.

See doc/gap-postmortem.md for the history of why this was hard. The short version: padding distorts the fill cell, transparent borders fight with background-clip, and both get devoured by sub-pixel rendering at deep cells. clip-path avoids layout entirely — pure paint.

1. Gap sweep (forward, 7 cells, fill)

The visible gap should stay constant between large and small cells. If clip-path scaled the gap with the cell, cell 5 would have a hair-thin gap and cell 7 would have none at all.

9. Content clipping — handled by default

clip-path trims pixels at paint time; it does not shrink the cell's layout box. Anything inside that reaches the cell edge — a border, a bleeding background, an absolutely-positioned badge, justified text — would get visually clipped by the gap.

To prevent this, setting --spiral-grid-gap also installs a matching safe zone on .spiral-grid__content via --spiral-grid-safe-zone (defaults to gap / 2, scale-compensated so the visible padding stays constant at every cell depth). Centered flex content doesn't notice; edge-bleeding content stays clear of the clip for free.

For full-bleed content (e.g. a photo that should reach all the way to the clip edge), opt out per spiral: 

.my-spiral { --spiral-grid-safe-zone: 0; }

Each cell below contains an inner box with a visible border. On the left the spiral sets --spiral-grid-safe-zone: 0 and the border gets eaten by the gap. On the right, the default safe zone keeps the border clear. Both use the same --spiral-grid-gap: 16px.

--spiral-grid-safe-zone: 0 — border edges get clipped

10. Self-scaling gap with container query units

When the gap is expressed as a container-relative unit (cqi, cqw, %…), it scales with the spiral's own width automatically. Every spiral below uses the exact same --spiral-grid-gap: 1.2cqi; the absolute gap is ~9.6px on the 800px stage and ~3.6px on the 300px stage, but the visual proportion is identical. This is the recommended pattern for responsive layouts.
