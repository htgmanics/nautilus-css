Infinite zoom — stacked layers, lap steps, forward only

Four full-size spirals stacked, layer k scaled by φ⁴ᵏ about the eye, so each one sits exactly in the previous one's fill cell. A step zooms the stack by scale(φ⁻⁴) rotate(−360°); when it lands, layer 1 occupies exactly layer 0's box, so we re-render with offset+4 and drop the transform in the same frame. Wheel = continuous, snaps to the nearest lap when idle.
