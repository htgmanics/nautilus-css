Where the project stands after the resume-from-hiatus sprint (2026-09-24 →
2026-09-29). Written as a handoff: what exists, what was decided and why,
what the numbers are, what's open. The roadmap (`publish-roadmap.md`) stays

---

## 1. State in one paragraph

**Nautilus** (`nautilus-grid` on npm — not yet published) is a golden-spiral
layout in pure CSS. The engine is a single 6×6 CSS Grid: ten cells share
only seven lines per axis, the six track sizes are powers of φ, and each cell
is one `grid-area`. No transforms, no `pow()`, 933 B gzipped. A React
wrapper (`nautilus-grid/react`) maps props to the classes. An infinite-zoom
"tunnel" prototype runs on top of it with a pixel-invisible reset. The
package builds, tests, and packs; the repo is `htgmanics/nautilus-grid`; the
demo is live on GitHub Pages. Publishing is halted by choice until the
example pages sell the idea rather than test it.

## 4. Decisions and why

Short form; the roadmap has the long form for each.

- **Plain CSS, no SCSS.** The only SCSS variable would be φ, which is frozen.
- **Name: `nautilus-grid`, brand Nautilus.** A project with a visual identity wants a brand name; "grid" carries the category; bare `nautilus` is taken on npm; scopes bake an org into every install line. Search intent lives in description + keywords. Superseded `golden-nautilus` (09-24) after the owner renamed the repo.
- **CSS Grid engine over transforms.** Same rectangles (0.02 px), no per-px scaling inside cells, `cqi` works per cell, native scrollbars, no `pow()`, half the bytes. The transform approach was the right *discovery* tool and the wrong *shipping* foundation. Zoom is unaffected: it was always a container transform about the eye.
- **Gap = `clip-path: inset(gap/2)` + `gap/2` content padding.** Grid `gap` distorts the squares; margin/padding on the cell feed track-sizing minimums and break the 1–2 px eye tracks. Clip-path never touches layout; nothing is scaled, so both are constants.
- **Fill cell via `:nth-last-child(1 of .nautilus__cell)`;** non-cell children auto-`position: absolute`. Overlays no longer take tracks or break the fill.
- **Tunnel: stacked layers, lap steps, no spin, forward only, recycle DOM.** Nesting in the fill cell has an unfixable rounding seam. Each layer animates its own transform so Chrome rasters it at target scale. Only the off-screen layer is refilled per lap.
- **React wrapper is thin on purpose.** Props → classes, enforces the cell/content pair, typed. No logic. Tailwind dropped; Svelte/Vue later.
- **Publish halted (09-29).** Showcase examples first, then zoom exploration, then resume the runbook.

## 6. Bugs found by measuring, not by looking

Recorded because each one *looked* fine first.

1. Grid `fr` factors summing < 1 are clamped to 1 → rows filled 61.8 %. Fix revealed rows = columns.
2. Margin gap: exact at 528 px, distorted at 215 px (track minimums). Only the gap sweep at small size showed it.
3. Nested-spiral zoom: 0.07–0.10 px seam that survived 9-digit constants — Chrome's 1/64 px layout rounding magnified 6.85×.
4. Wrapper-animated zoom: blurry mid-lap; measured 6.2 vs 16.5 after per-layer animations.
5. Lazy-loading photos at depth ≤ 2: a 13 px cell popped from colour to photo at reset (131 px diff). Load at depth ≤ 3.
6. `<span>` eye markers inside the grid took a track and broke `:last-child` fill.
